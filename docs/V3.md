# RealityHD 3.0

3.0 is the agent release. A coding agent can take a prop from a one-line request to a signed-off,
photoreal, tested asset with a fixed command loop and a bounded token cost, and the package records
how good the result is.

## Pipeline

```
request ──> brief ──> scaffold ──> build(seed:) ──> lint ──> gate sheet (+ reference compare)
                                       ^                              │
                                       └──── fixes <── vision verdict ┘
                                                          │ pass
                                                          v
                                          signoff ──> thumbs ──> catalog ──> swift test
```

| Stage | Command | Output |
|---|---|---|
| Context | `realityhd context prop` | API, every material key, props by theme, loop commands (replaces reading sources) |
| Brief | `realityhd brief <id>` | `briefs/<id>.json`: size, parts, materials, style, budget, references, threshold |
| Scaffold | `realityhd new prop <id> --brief briefs/<id>.json` | source with brief size, summary, tags, budget; registered |
| Lint | `realityhd lint <id>` | budget, LOD order, floating/sunk, centering, texel density per material, size vs brief |
| Sheet | `realityhd sheet <id>` | six views on a studio floor plus golden-hour grazing light, stats header |
| Gate | `realityhd gate <id> [--ref img]` | `report.json`, `sheet.png`, `compare.png`, verdict template |
| Verdict | agent Reads the sheet, or `Scripts/vision_judge.py` | `verdict.json`: nine 0-10 criteria with anchors, fixes |
| Score | `realityhd gate <id> --verdict v.json [--signoff]` | final confidence, pass/fail reasons, `briefs/signoff/<id>.json` |

## Score

Automated part: lint score, size match (Gaussian per axis, 0.5 at the brief tolerance), and with a
reference photo: silhouette IoU after a camera search, Vision feature-print similarity, mean Lab color
distance, bounding-box aspect and detail energy. The reference subject is lifted with
`VNGenerateForegroundInstanceMaskRequest`; renders use a magenta matte.

Vision part: weighted mean of the rubric (silhouette 1.2, proportion 1.0, construction 1.3, edges 0.8,
materials 1.4, wear 0.8, grounding 0.5, artifacts 1.0, reference 1.5).

final = 0.35 automated + 0.65 vision, or 0.5 / 0.5 with a reference. Pass: final >= threshold (0.85
default), every criterion >= 6, no lint errors. A sign-off stores a geometry fingerprint; tests fail
when the asset changes after sign-off.

## Geometry kit (RealCore/Shapes.swift, RealLibrary/Building/Details.swift)

`Shape2D` outlines (rect, roundedRect, circle, superellipse, polygon, fillet, offset, triangulate),
`Prim.extrude` with beveled caps, `Prim.sweep` (any section along a path, grain along the path),
`Prim.loft` + `Prim.ring`, `Prim.superellipsoid`, `Prim.torus`, `Prim.helix`, `Prim.cylinder`,
`Profile` helpers, `Surface.deform/displace/subdivided/flipped`. Hardware: `rivet`, `rivetRow`,
`hexBolt`, `stitches`, `barHandle`, `chain`, `caster`, `panelWithBead`, `tuftedPanel`, `buttons`.

## Materials

Programs `leather`, `brushedMetal`, `polishedMetal` (hammered dents, tarnish, verdigris),
`ceramicGlaze`, `caneWeave` (octagonal cutout). 29 keys in `Library/Craft.swift`: leathers, brass,
copper, aluminum, stainless, chrome, powder coat, enamel, cast iron, four ceramics, cane, wicker,
beech, walnut, mahogany, rattan, aged pine, mossy granite, bulb glow.

## Agent skills (.claude/skills)

`realityhd-prop` (end to end), `realityhd-brief`, `realityhd-gate` (judge and sign off),
`realityhd-material`. Each keeps file reads to what a step names; the CLI prints one stat line per
step.

## Token budget per prop

| Step | Typical cost |
|---|---|
| `realityhd context prop` | ~6k tokens once |
| Brief + scaffold | ~1k |
| `build(seed:)` | 150-250 lines of Swift |
| Each gate iteration | one 1920x1024 sheet image + a 300-token verdict |
| Iterations to pass | 2-4 for the ten 3.0 props |
