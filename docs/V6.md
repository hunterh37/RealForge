# RealityHD 6 plan (household)

Status: planned. Work starts after the in-flight RealKit performance change lands (see Coordination).

6.0 adds 50 household props (33 articulated, 13 handheld), five house structures, a `HousePlan`
builder for multi-room, multi-storey shells, and the `two-story-house` scene. Briefs for every asset
are in `briefs/household/<id>.json`. That folder sits outside the `briefsMatchAssets` test; move a
brief to `briefs/<id>.json` in the PR that adds its asset.

`batchStatics = true`. Camera opens in the living room at 1.6 m eye height looking toward the kitchen.

## Engine

| Item | Where | Notes |
|---|---|---|
| `HousePlan` | `RealLibrary/Building/House.swift` (new) | rooms as rects per floor; walls as a graph of segments so partitions are single (Room builds closed boxes and would double them); per-side face material, skirting and door casing on both faces; openings carry the structure that fills them; returns `shell(floor:)`, `slab(floor:)` with stair void, `ceiling(floor:)`, `exterior()` (3 LODs), `roof()`, and `fixtures` (opening transforms for doors and windows) |
| Exterior LOD | same file | LOD0 full trim, LOD1 drops gutters, soffit detail and siding courses to normal map, LOD2 box with roof for > 60 m |
| `InteriorLight.home` | `RealKit/Environment.swift` | warm 3000 K ceiling, window band. File is in-flight; add after it lands, use `.warm` until then |
| Floor visibility | `RealScene` zones (new, small) | tag statics and live rigs with a floor index; viewer on floor 0 hides floor 1 interiors except the stair void band, and the reverse. Cuts drawn triangles about 45 percent. File is in-flight |
| Switch to light links | `RealArticulated` runtime | `light-switch` state drives a named light group (ceiling-fan light, lamps); one `RealLinkComponent` with target names |
| Water streams | `water.stream` option geometry | faucet, tub, shower: a tapered tube option with scrolling UV; no particles |
| Fabric drape helper | `RealCore` | `Prim.drape(rect, over: [Surface], sag:)` for duvets, towels and tablecloth edges; vertical ray drop onto a coarse BVH, then smooth |
| Ceiling fan spin | `RealArticulationSystem` | optional `.spin(rpm)` joint mode for blades and the washer drum; idle cost zero when off |

thumbnail, catalog). Articulated assets also pass `realityhd states <id>` and `ArticulationTests`.

| 2 | Kitchen: 18 props | 0 |
| 3 | Living and Home: 16 props | 0 |
| 4 | Bedroom, Bathroom, Laundry: 16 props | 0 |

| 6 | Furnish `two-story-house`, thumbnails, Demo case, CATALOG, `docs/V6.md` release notes | 1-5 |

`Props/Props.swift` and `Structures/Structures.swift` conflict on the marker line; rebase and rerun
`realityhd catalog` at merge.
