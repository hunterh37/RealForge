# RealityHD 5.0

5.0 adds an emergency department: four hospital scenes, 43 articulated medical props, 7 articulated
hospital structures, hand grab for handheld assets, five texture programs and 109 material keys. It
also ships the performance layer (`RealPerformance`, docs/guides/performance.md).

## Scenes

| id | contents |
|---|---|
| `hospital` | lobby, 16 m treatment corridor with scrub sink and parked equipment, ER room, operating room |
| `hospital-lobby` | glazed entrance, intake nurse station, check-in kiosks, beam seating, wheelchairs, treatment doors |
| `er-room` | stretcher under a lit headwall, vitals monitor, IV pump, exam table and stool, instrument counter, crash cart, curtain |
| `operating-room` | operating table, dual-head LED light, anesthesia boom and workstation, Mayo stand, back table with instruments |

`hospital` is built by `RealScene.merge(_:at:)` from the three room builders: each room is a
`Room` shell, rooms sit back to back with their door openings aligned. All interiors use
`batchStatics` and the AO bake; lighting comes from `InteriorLight.clinical` or `.operatingRoom`.

## Assets

Every asset conforms to `RealArticulated`, has 2 to 5 named states, 2 or 3 LODs, a brief and a gate
sign-off (`briefs/signoff/`). `realityhd states <id>` renders every state.

| group | ids |
|---|---|
| surgical (handheld) | surgical-scissors, hemostat, needle-holder, tissue-forceps, scalpel, weitlaner-retractor |
| diagnostic (handheld) | stethoscope, otoscope, penlight, reflex-hammer, tympanic-thermometer, pulse-oximeter, laryngoscope |
| bedside | sphygmomanometer, syringe, aed, glucometer (handheld); iv-pole, infusion-pump, patient-monitor |
| patient furniture | exam-table, er-stretcher, hospital-bed, overbed-table, doctor-stool, wheelchair |
| theatre | operating-table, mayo-stand, anesthesia-machine, instrument-container (handheld), crash-cart, biohazard-bin |
| clinic | pill-bottle, oxygen-cylinder, clipboard-chart (handheld); sharps-container, sanitizer-dispenser, medical-scale, supply-cabinet, microscope |
| lobby | beam-seating, check-in-kiosk, xray-viewer |
| structures | hospital-doors, surgical-light, ceiling-boom, scrub-sink, privacy-curtain, headwall, nurse-station |

Budgets: handheld instruments 3 to 5k triangles at LOD0 with LOD1 at 25 to 40 %, devices 5 to 9k,
furniture and structures 9 to 17k. Small details (screws, labels, knurls) live in LOD0 only.

Wall-mounted assets keep their lowest point at y = 0; place them at mounting height
(sanitizer-dispenser about 1.0 m, sharps-container 1.2 m, xray-viewer 1.3 m, headwall 1.15 m,
privacy-curtain 0.3 m). Ceiling-mounted structures (`surgical-light`, `ceiling-boom`, tag `ceiling`)
are authored under a ceiling at `mountHeight` with y = 0 the floor.

## Hand grab

```swift
let hemostat = try await RealityHD.articulated("hemostat")       // tagged handheld: grabbable
scene.addLive(Stethoscope(), at: place(2.7, -1.4, y: 0.91), seed: 1)   // grabbable in the scene
let cart = try await RealityHD.articulated("crash-cart", grabbable: true)
```

A grabbable root gets a solid box over `Rig.restBounds` and a `ManipulationComponent` (visionOS 26,
release behavior `.stay`, no scaling). Part tap targets stay, so a pinch on the body moves the object
and a tap on a jaw or lid toggles it. `resetGrab()` returns it to where it was placed.
