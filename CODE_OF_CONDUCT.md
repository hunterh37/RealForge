# Code of conduct

RealForge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior to the maintainers through a private message on GitHub (open a
[security advisory](https://github.com/hunterh37/RealForge/security/advisories/new) if no other
channel fits). Reports are handled privately. Maintainers may remove comments, commits and
contributions, and ban contributors, for behavior covered by the Covenant.
