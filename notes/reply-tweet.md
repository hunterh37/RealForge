Every object in this Apple Vision Pro hospital is procedural Swift code. Claude Opus 5.5 writes the geometry and materials, then my vision pipeline renders each asset and grades it against reference photos until it passes.

ER, operating room, lobby and 60+ grabbable medical props, running live in RealityKit.

Releasing the medical scenes and props free as an open-source Swift package.

Alt (shorter):
I gave Claude Opus 5.5 a custom vision pipeline so it can build photoreal RealityKit assets for Apple Vision Pro. This hospital and every prop in it came out of that loop. The medical scenes ship free as an open-source Swift package.
